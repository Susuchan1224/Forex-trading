# Kurumi FX 学院 · 反 FX 赌博劝导网页

> 《FX战士久留美》同人学习作品。用你喜欢的动画，讲清楚 FX 赌博的实质。
> 非官方、无商业用途。所有行情数字均为模拟数据，不构成任何投资建议。

## 一句话概述

一个「渐进式异化」的交互网页：表面是专业的 FX 交易教学平台，随着向下滚动，
逐渐暴露赌徒心理陷阱与强平爆仓的真实后果。

技术内核参考 [Hearthly](https://github.com/jikol1906/Hearthly)，叙事主题、视觉设计、
颜料转场与后端联动为原创。

## 叙事结构（v4）

v3 的「关于讲师」提前是对的，但后面几段堆了太多东西：手机推送、自己的行为记录、
一整屏「真相」。这一版把它们删掉，只留一条主线——

**一切正常 → 有个人不对劲 → 你会怎么想 → 行情崩了 → 掉下去 → 系统日志 → 一句风险提示。**

删掉的两段各有理由：
- **手机推送**：需要读者先在脑子里补一个「这是我的手机」，而画面里没有手机，读起来是别人的事。
- **「本页一直在数」**：它靠真数据成立，但也就意味着冷启动时读者看到的是「0 人」，
  反而证明这页没人看。恐怖要靠确定性，不能靠赌。

## 核心机制

### 1. 颜料转场：画在段落自己的墙上

动画里的转场是液体颜料喷在墙上：前半段五颜六色，亏钱之后变成暗红。

v3 用的是 `position:fixed` 的全屏画布。视觉上没错，但一滚轮就露馅：
屏幕在动，颜料钉在视口上，像贴在玻璃前的一张纸。

现在**每个段落自己持有一张绝对定位的画布**（`canvas.burst`，`z-index:0`，
正文在 `z-index:1`）：

- **随页面滚动**：颜料喷在这一屏的墙上，会跟着段落一起走掉
- **左右各喷一次**：两个喷射源从段落两侧的边缘向内对撞，
  高度对准该段的标题（`opts.ref`），段落比视口高时也不会喷到屏幕外
- **不压底色**：画布在正文之下、页面底色之上，所以不需要任何半透明色罩。
  早期用 `veil` 压黑，浅色段的深色正文会直接消失
- **彩带**：05 学员故事额外从标题处像礼炮一样炸出一把彩带（`makeConfetti`），
  受重力下坠、旋转、飘摆，带一圈极淡的暗边以免落在同色颜料上看不见

颜料本身的画法沿用 v3：

- **四层密度**：核心团块 18 块（r 26–84，叠成一整片）→ 中块 26 → 小块 44 → 颗粒 88，
  距离按指数衰减堆在喷射源附近。均匀随机会撒成彩纸
- **形状**：极坐标抖动的多边形 + 二次曲线过中点平滑；沿喷射方向拉伸并拖一条锥形尾
  —— 这是「液体」和「色块」最大的区别
- **拖丝**：每个源 18 条贝塞尔，采样成由粗到细的锥形体，尾巴挂一颗珠子
- **挂住**：按出生时间**永久画进离屏缓冲**，主画布每帧只做 `drawImage` + 淡出
- **边缘**：画布就是段落边界，所以上下各留 7% 的遮罩过渡，
  喷到边界是「散开了」而不是被切出一条直线

三档调色板，同一个函数只换颜色：

```js
bright: 糖纸色            // 05 学员故事：全页最快乐的一屏
wrong:  混进一块 #6E0C14  // 06 讲师：还是彩色，但有一个颜色不对
red:    暗红，往下淌      // 09 那根长阴线落下来的时候
```

### 2. 坠落：只发生一次的事件

这一段曾经是一个 240vh 的粘性舞台，于是它是「随滚动从下往上推上来」的，
像滑进来的贴图；而且往回滚可以重看，恐怖感全没了。

现在是固定层 `#fall`，由 `playFall()` 触发一次：

```
图表滚到底、52 根 K 线全部揭示
  → 800ms 后：故障转场（切片反相错位 + 画面本体抖动）
  → 黑场淡入 0.85s（是淡入，不是平移）
  → 久留美被漩涡吸向中心：scale 1.02 → 0.14，下沉，旋转 −16°，透明度归零
  → 1s 淡出，露出下一部分
```

- **不可回看**：`fallDone` 锁死，且它不挂在滚动上，回滚也没有东西可重放
- **淡出到下一部分**：幕布盖住画面时把滚动位置挪到系统日志，
  否则淡出后露出来的还是那张图表
- **故障转场**用 `backdrop-filter:invert()` 切 8 条横向窄带，
  各自位移、闪烁、错相 —— 切片位移时采样到的背景跟着位移，
  看起来是画面被撕开，而不是盖了一条黑条。同时 `main` 整体错位两下
- **漩涡不露边**：那张图整张在慢慢旋转，元素必须是边长 ≥ √2·max(vw,vh) 的正方形，
  否则转到 45° 就把图框的直角露出来。另外全局 `img{max-width:100%}` 会把它压回视口宽，
  必须显式 `max-width:none`

### 3. 天色：从「真实交易者心态」开始沉下去

要求是「背景逐步变黑」，难点不在变黑，在**字**。

底色和文字色如果线性同时插值，会在中途撞在一起：
`#D3D9E8→#141A24` 走到 50% 是 `#787e8b`，`#16213A→#E2E8F0` 走到 50% 是 `#778091`
—— 几乎同一个颜色，正文直接消失（实测对比度 1.0:1）。

两个补丁：

1. **文字色滞后**（`fp = clamp((p - .55) / .45)`）。等它开始变亮时天色已经压得很暗，
   于是字是「在深底上变亮」，越变越清楚而不是越变越糊
2. **卡片自带一张纸**（`#mindset .thought` 固定浅底 + 固定深字）。底色怎么变它都不参与，
   也正好读成「墙上剩下的最后几张便条」

另外 `.dusk`（底部起、向上扩散的渐变）与 `.grain`（SVG 湍流颗粒）叠在这段里，
`opacity` 由滚动进度写入 —— 所以是「一路沉下去」，而不是滚到边界突然换色。

### 4. 单一账户模型 + 单一行情源

```js
const LEVERAGE = 25;
notional    = usedMargin × leverage        // 120,000 × 25 = 3,000,000
pnlPerYen   = notional ÷ price             // ≈ 19,355 日元 / 每 1 日元波动
equity      = deposit + floatingPnl
marginLevel = equity ÷ usedMargin × 100
```

`usedMargin` 占本金 40%，是「赌徒」的仓位而不是理性仓位——叙事需要的设定。
维持率分级：`≥200% 充足 / ≥100% 注意 / ≥50% 危险 / <50% 即将强平`。

> 现实参照：日本个人 FX 杠杆上限 25 倍（2011 年 8 月起），多数业者维持率 100% 发追证、
> 50% 强制平仓。页面按此简化，但**不能当作实际交易依据**。

图表面板里的盈亏不是另一个字符串，而是「最后一根已揭示 K 线的收盘价」换算出来的。

### 5. 滚动引擎与「事件」

`requestAnimationFrame` + `ticking` 节流，`--d` 驱动噪点、暗角、扫描线与灰化滤镜。
灰化最大只到 `grayscale(.22)`——早期版本用 `.35`，把「我决定远离 FX」这个唯一的
行动按钮也一起灰掉了。

一次性事件用布尔量锁死：

| 段落 | 驱动 | 实现 |
|------|------|------|
| 颜料转场 | 段落位置（阈值 40% 视口） | 命中后 `splash()`，`burstFired` 锁死 |
| K 线 | `.chart-panel` 位置 | 面板顶端升到视口 25% 处时 52 根全部揭示 |
| 坠落 | 最后一根 K 线 | `playFall()`，`fallDone` 锁死 |
| 系统日志 | 粘性进度（280vh） | 按进度给 `.l` 加 `.on` |

**K 线为什么文字用 HTML**：SVG 用了 `preserveAspectRatio="none"`，文字放进去会被
横向压扁（296px 宽的容器里会压到 30%）。所以 SVG 只画矩形和线。

### 6. 回顶清算

只改文案不够——白底蓝字里写着「它一直在等你回来」，情绪是错的。
接近顶部时 `--bg / --fg / --accent` 会被插值压成近黑 + 血红，越往下滚恢复得越多。

爆仓动画必须等用户真正看到才启动（`scrollend`），否则 300,000 → 0 的暴跌会全部
发生在屏幕外。中间的 `#scare` 是一层全屏惊吓。

### 7. Web Audio

零音频文件，全部 `AudioContext` 合成：pad / drone / 心跳 / crash（低频下坠 + 噪声爆点）
/ splash（一声上扬的唰）/ scare。

音频必须由用户手势解锁，所以首屏的「开启氛围音效」是入口。没有音频时，
所有冲击都有**视觉替代**（全屏闪、震屏），不会因为静音就没有反馈。

```

├── docs/
│   ├── index.html            12 个叙事段落 + 坠落/故障/惊吓三个覆盖层
```

## 快速开始

```bash
cd backend && npm install && npm start
# http://localhost:3001
```

仅看前端：直接打开 `docs/index.html`。视觉、滚动叙事、颜料转场、坠落、回顶清算全部可用；
只有结尾统计会降级为基线值。
